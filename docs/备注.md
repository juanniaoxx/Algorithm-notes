# 📝 网站使用备注
## 项目结构

| 路径 | 说明 |
|------|------|
| `docs/index.md` | 首页，使用 `home.html` 模板渲染 |
| `docs/备注.md` | 本文件，网站使用说明书 |
| `docs/blog/` | 博客文章目录 |
| `docs/overrides/404.html` | 404 页面，数字雨黑客风格 |
| `docs/overrides/home.html` | 首页独立模板，含开屏动画和卡片网格 |
| `docs/overrides/main.html` | 内页模板，继承 MkDocs `base.html` |
| `docs/overrides/partials/` | 可复用模板片段（公告、页脚等） |
| `theme/css/core/` | CSS 变量定义 + 全局基础样式 |
| `theme/css/components/` | 组件样式，按功能拆分（代码块、表格、提示框等） |
| `theme/css/pages/` | 页面专属样式（首页、内页） |
| `theme/css/utils/` | 工具类样式（响应式、打印） |
| `theme/js/core/` | 核心 JS（数字雨背景、光标光晕、工具函数） |
| `theme/js/components/` | 组件 JS，按功能拆分（复制、TOC、展开等） |
| `theme/js/pages/` | 页面专属 JS（首页逻辑、内页逻辑） |
| `theme/js/data/topics.json` | 首页卡片数据，每个卡片一个对象 |

## 视频时间戳

在 `<video data-cyber-player>` 标签下方写笔记时，用 `[MM:SS]` 标记时间点：

```markdown
<video data-cyber-player style="width:100%; aspect-ratio:16/9;">
    <source src="视频地址.mp4" type="video/mp4">
</video>

- [00:05] 组件名必须以大写字母开头
- [00:08] useEffect 的依赖数组不能省略
```

效果：点击 `[00:05]` 视频会跳到 5 秒并自动播放，边框闪蓝光。

注意：
- 时间戳不要用 `` `[00:05]` `` 反引号包裹，直接写纯文本
- 时间戳放在 admonition 外面才能生效

## 可折叠书籍列表

```markdown
<div class="collapsible">
    <div class="collapsible-header">
        <strong><span class="collapsible-icon">📚</span>分类名<span class="collapsible-count">(数量)</span></strong>
        <span class="collapsible-toggle"><span>收起</span><span class="toggle-icon">▼</span></span>
    </div>
    <div class="collapsible-content">
        <a href="链接" class="collapsible-item">
            <span><span class="item-icon">📖</span>书名</span>
            <span class="item-badge item-badge-pdf">PDF</span>
        </a>
    </div>
</div>
```

复制上面整段，改分类名、数量、书名和链接即可。每加一本书复制一行。

## 提示框

```markdown
!!! info "信息"
    蓝色边框，一般说明

!!! tip "提示"
    绿色边框，建议或技巧

!!! warning "注意"
    琥珀色边框，需留意

!!! danger "危险"
    粉色边框，常见陷阱
```

## 首页卡片数据

所有卡片数据在 `docs/theme/js/data/topics.json`，每本书一个对象。格式：

```json
{
    "cate": "分类",
    "title": "书名",
    "icon": "📖",
    "iconBg": "rgba(0,212,255,0.15)",
    "desc": "简短描述",
    "intro": "详细介绍",
    "difficulty": "beginner|intermediate|advanced",
    "books": 1,
    "link": "/跳转路径/",
    "stars": 5
}
```



## 课程表

使用下方 HTML 结构生成课程表，配合已有的 `\theme\css\components\schedule` CSS 样式使用。


```html
<div class="schedule-wrapper">
<table class="schedule-table">
  <thead>
    <tr><th>日期</th><th>章节</th><th>学习内容</th><th>实验</th></tr>
  </thead>
  <tbody>
    <tr class="week-separator"><td colspan="4">⚡ 第1周 · 主题</td></tr>
    <tr><td>第1天</td><td><span class="schedule-chap">Ch.1</span></td><td>内容描述</td><td>课后练习</td></tr>
    <tr><td>第2天</td><td><span class="schedule-chap">Ch.2</span></td><td>内容描述</td><td><span class="schedule-lab">实验名</span></td></tr>
    <!-- 继续添加行 -->
  </tbody>
</table>
</div>
```
