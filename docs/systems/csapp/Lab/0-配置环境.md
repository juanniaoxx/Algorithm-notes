## 环境配置

优先使用`docker`， 使用社区已经做好的完整的 dcoker 镜像来一步安装好点. 

[CS:APP Docker and Materials](https://github.com/XieGuochao/csapp)

```Shell
docker run -p 7777:7777 -v "$PWD/labs:/home/csapp/project" --platform linux/amd64 xieguochao/csapp
```

虽然项目自带一个网页端的 vscode 但还是用自己本地的配置好的 vscode 好点。

1. 下载 `Dev Containers`拓展
2. 使用 `cmd+shift+p` 输入 `Dev Containers: Attach to Running Container`
3. 选择 `xieguochao/csapp`容器

## 实验相关备注 

### Data Lab 

!!! tip 
    Students implement simple logical, two's complement, and floating point functions, but using a highly restricted subset of C. For example, they might be asked to compute the absolute value of a number using only bit-level operations and straightline code. This lab helps students understand the bit-level representations of C data types and the bit-level behavior of the operations on data.
