## Practice Problem 
!!! info "Conversion Exercises"
    Perform the following number conversions:

    A. 0x25B9D2 to binary  
    B. binary 1010111001001001 to hexadecimal  
    C. 0xA8B3D to binary  
    D. binary 11001000101101100101110 to hexadecimal

    ??? tip "Solution"
        
        - 0010 0101 1011 1001 1101 0010
        - 0xAE49
        - 1010 1000 1011 0011 1101
        - 0x322D96

!!! info "Conversion Exercises"
    Fill in the blank entries in the following table, giving the decimal and hexadecimal representations of different powers of 2:

    <div style="display: flex; justify-content: center;">

    | n | 2<sup>n</sup> (decimal) | 2<sup>n</sup> (hexadecimal) |
    |---|---|---|
    | 5 | 32 | 0x20 |
    | 23 |   |   |
    |   | 32,768 | 0x2000 |
    | 12 |   |   |
    |   | 64 | 0x100 |

    </div>

    ??? tip "Solution"
        <div style="display: flex; justify-content: center;">

        | n | 2<sup>n</sup> (decimal) | 2<sup>n</sup> (hexadecimal) |
        |---|---|---|
        | 5 | 32 | 0x20 |
        | 23 | <span style="color: red;">8,388,608</span> | <span style="color: red;">0x800000</span> |
        | 15 | 32,768 | <span style="color: red;">0x8000</span> |
        | 12 | <span style="color: red;">4,096</span> | <span style="color: red;">0x1000</span> |
        | <span style="color: red;">6</span> | 64 | <span style="color: red;">0x40</span> |

        </div>

!!! info "Conversion Exercises"
