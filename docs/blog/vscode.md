## 🎯 核心查找与导航快捷键

| 功能分类 | Windows / Linux | Mac | 说明 |
| :--- | :--- | :--- | :--- |
| **快速打开文件** | `Ctrl + P` | `Cmd + P` | 输入文件名模糊匹配并打开文件，这是最常用的 。 |
| **全局搜索** | `Ctrl + Shift + F` | `Cmd + Shift + F` | 在整个项目文件夹中搜索文本内容 。 |
| **打开命令面板** | `Ctrl + Shift + P` | `Cmd + Shift + P` | 执行几乎任何命令、安装插件、更改设置的核心入口 。 |
| **切换文件** | `Ctrl + Tab` | `Cmd + Option + →/←` | 快速切换最近打开的文件列表 。 |
| **跳转到指定行** | `Ctrl + G` | `Ctrl + G`| 输入行号，光标直接跳转 。 |
| **查找符号** | `Ctrl + T` | `Cmd + T` | 在工作区中查找函数、类、变量等符号 。 |
| **跳转到定义** | `F12` 或 `Ctrl + 点击` | `F12` 或 `Cmd + 点击` | 跳转到函数或变量的定义位置 。 |

## ✨ 高效编辑与界面快捷键

| 功能分类 | Windows / Linux | Mac | 说明 |
| :--- | :--- | :--- | :--- |
| **多光标编辑** | `Alt + 点击` 或 `Ctrl + Alt + ↑/↓` | `Option + 点击` 或 `Option + Cmd + ↑/↓` | 在多个位置创建光标，可以同时编辑多行代码 。 |
| **选择所有匹配项** | `Ctrl + Shift + L` | `Cmd + Shift + L` | 选中当前文件中所有与高亮词相同的词，可批量修改 。 |
| **格式化代码** | `Shift + Alt + F` | `Shift + Option + F` | 自动整理代码，使其缩进对齐，整洁美观 。 |
| **复制/移动行** | 复制: `Shift + Alt + ↑/↓`<br>移动: `Alt + ↑/↓` | 复制: `Shift + Option + ↑/↓`<br>移动: `Option + ↑/↓` | 快速复制或上下移动当前行代码 。 |
| **注释代码** | `Ctrl + /` | `Cmd + /` | 注释或取消注释当前行或选中的代码块 。 |
| **重命名变量** | `F2` | `F2` | 自动重命名文件中所有出现该变量的地方，非常安全高效 。 |
| **切换侧边栏** | `Ctrl + B` | `Cmd + B` | 显示或隐藏左侧的文件资源管理器，提供更广阔的编辑界面 。 |
| **打开/关闭终端** | `` Ctrl + ` `` | `` Ctrl + ` `` | 调出或隐藏内置的命令行终端 。 |


### 📝 附：Mac 专用符号说明

Mac 键盘上的特殊按键通常用符号表示，你可以对照下图理解：

*   **⌘**：Command 键
*   **⌥**：Option 键
*   **⇧**：Shift 键
*   **⌃**：Control 键

## 自定义快捷键 

`cmd + k` 紧接着按 `cmd + s` 可以打开 vscode 快捷键设置方式。 

- 在资源管理器中新建文件(`explorer.newFile`) 
    - 目前绑定按键 `Cmd + N` 覆盖率原本的新建文件逻辑 
- 在资源管理器中新建文件夹(`explorer.newFolder`)
    - 目前绑定按键 `Cmd+Shift+N`
