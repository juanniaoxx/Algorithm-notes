!!! Info  "Generic Stack"
    **泛型栈** 是一种**可以存储任意类型数据**的栈容器。栈遵循 **LIFO（后进先出）** 原则，
    
    主要操作包括：`push`（压入）、`pop`（弹出）、`top`（查看栈顶）。
    
    **泛型**意味着栈的数据类型由使用者指定（例如 `Stack<int>`、`Stack<std::string>`），是 C++ 模板的经典应用。 

**为什么要实现它？** 
 
- 深入理解 **C++ 模板**：学习如何编写与类型无关的容器。  
- 掌握 **动态内存管理**：手动管理堆内存，熟悉 `new`/`delete` 与 placement new。  
- 练习 **RAII 与三大/五大法则**：构造、析构、拷贝控制、移动语义。  
- 体验 **异常安全**：如何处理空栈、内存分配失败等情况。  
- 为后续学习标准库容器（如 `std::stack`、`std::vector`）打下基础。

通过这个 Lab，你将亲手实现一个可投入使用的轻量级栈容器，并理解现代 C++ 的核心设计理念。

我们将实现过程划分为 5 个阶段，每个阶段有明确的子目标。

## 阶段 0：准备工作

- 理解栈的 LIFO 行为。
- 复习 C++ 模板基础语法。
- 复习 `new` / `delete` 与 placement new（`new (ptr) T(args)`）。
- 理解 RAII：为什么栈对象应自动管理内存。

## 阶段 1：构造、析构与基本存储（`data_`, `capacity_`, `size_`）
**任务**：

- 实现默认构造函数：分配初始容量（比如 8）的原始内存，`data_` 指向它，`capacity_` 设为此值，`size_` 设为 0。  
   *提示*：使用 `::operator new` 分配原始内存，不要调用元素构造函数。
- 实现带容量参数的构造函数。
- 实现析构函数：先调用 `destroy()` 析构所有元素，再用 `::operator delete` 释放原始内存。
- 实现 `empty()` / `size()`。

**验证**：创建 `Stack<int>`，检查 `empty()` 和 `size()` 正确。

## 阶段 2：核心操作 `push` / `pop` / `top`

可以先假设容量足够

**任务**：

- 实现 `push(const T&)`：在 `data_ + size_` 位置使用 placement new 构造元素，然后 `++size_`。
- 实现 `pop()`：先检查非空，然后调用栈顶元素的析构函数 `data_[size_-1].~T()`，再 `--size_`。
- 实现 `top()`：返回 `data_[size_-1]`（注意 const 版本和空栈异常）。

**验证**：压入几个值，逐个弹出并检查顺序；尝试对空栈 `pop` 应捕获异常。

## 阶段 3：动态扩容（`resize`）

**任务**：

实现 `resize()`：  

   - 新容量 = `capacity_ * 2`（或 `capacity_ + 10`）。  
   - 分配新原始内存。  
   - 将旧元素**移动**到新内存（使用 `std::move` 提高效率）。  
   - 析构旧元素，释放旧内存。  
   - 更新 `data_`, `capacity_`。

修改 `push`，在 `size_ == capacity_` 时调用 `resize()`。

**验证**：压入超过初始容量的元素，检查栈仍正常工作且无内存泄漏。

## 阶段 4：拷贝控制与移动语义

**任务**：

- 实现拷贝构造：深拷贝整个栈。  
- 实现拷贝赋值：使用 **copy-and-swap** 惯用法（先创建局部副本，再调用 `swap`）。  
- 实现移动构造：直接将 `other` 的指针、容量、大小赋值给 `*this`，并将 `other` 置于“空”状态（`data_ = nullptr; capacity_ = size_ = 0`）。  
- 实现移动赋值：释放自身资源，然后与 `other` 交换。  
- 实现 `swap` 成员（交换所有成员）。

**验证**：测试拷贝后独立修改；测试移动后原栈变为空；测试自赋值安全。

## 阶段 5：完善与清理
- 实现 `clear()`：循环 `pop` 直至空。
- 增加 `push(T&&)` 重载（移动版本），提高性能。
- 添加 `noexcept` 标记适合的函数。
- 确保所有测试通过，无内存泄漏。

## 进阶挑战（可选）

完成基本要求后，可以挑战以下扩展：

1. **支持 `emplace`**  
   添加 `template <typename... Args> void emplace(Args&&... args)`，直接在栈顶构造对象，避免拷贝/移动。

2. **自定义扩容策略**  
   增加 `reserve(size_t new_cap)` 方法，允许用户预分配空间；让 `resize` 支持缩小容量

3. **实现迭代器**  
   为栈提供正向迭代器（从栈底到栈顶），虽然栈通常不提供，但可作为容器接口练习。

4. **支持 `std::initializer_list` 构造**  
   例如 `Stack<int> s = {1,2,3};`。

5. **与标准库兼容**  
   为栈提供 `using value_type = T;` 等类型别名，并实现 `stack` 适配器模式。

6. **异常安全强化**  
   在 `push` 中处理内存分配失败或元素构造抛异常的情况，确保栈状态不变（强异常安全）。

7. **性能对比**  
   实现一个简单的基准测试，将自己实现的栈与 `std::stack`（底层为 `std::deque`）对比压栈/弹栈性能，分析差异。
