## Note 

- C++ 是静态（通常归类为弱类型）编译型语言
    - 静态(statically typed)：类型检查在编译时完成，对象的类型在编译期就已确定
        - 对象的类型决定了可以对它进行哪些操作（The type determines applicable operations）
    - 编译型：源代码(.cpp)通过编译器(compiler)转换为目标文件(.o/.obj)，
      再通过链接器(linker)进行静态链接或动态链接，
      最终生成可执行文件(.exe 或 ELF 格式的二进制文件)
- The C++ standard Library can be implemented in C++ itself(most).
